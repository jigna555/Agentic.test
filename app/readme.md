# agentic Ai app

## prerequisited

-pyhon3.x.x
-Gemini Api key

## Installation

-create virtual env

'''bash
python -m venv v_env
'''

-Activate avirtual env

win - CMD

'''bash
v_env/Script/Active.bat
'''

Win - pscd app

'''bash
v_env/Script/Active.ps
'''

-Install packages

'''bash
pip install -r requairement.txt
'''

-Run code

'''bash
python main.py
'''
